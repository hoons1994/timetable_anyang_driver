# timetable_anyang_driver

안양대학교 시간표 Excel 데이터를 읽어 공통 시간표 데이터 구조로 변환하기 위한 PHP 드라이버입니다.

`anyang.driver.php`의 `timetableDriver` 클래스는 상위 `timetable` 클래스를 확장하며, Excel 행에서 과목·분반·교수·전공·강의실·강의시간 정보를 추출합니다.

## 주요 기능

- Excel 형식 시간표 데이터 파싱
- 과목, 분반, 교수, 전공 정보 추출
- 월요일~토요일 강의시간 처리
- 여러 개의 강의시간/강의실 항목 처리
- 교시 번호를 분 단위 시작/종료 시각으로 변환
- 누락되거나 일부 잘못된 Excel 데이터에 대한 방어 처리
- PHP 8.4 호환성 대응

timetable_anyang_driver/

## 클래스 구조

```php
class timetableDriver extends timetable
```

이 드라이버는 독립 실행형 애플리케이션이 아니라, `timetable` 클래스를 제공하는 상위 시간표 시스템에서 사용하는 것을 전제로 합니다.

지원 업데이트 형식은 Excel입니다.

```php
public $update_type = array('excel');
```

## 요일 인덱스

`init()`에서 다음과 같이 요일을 정의합니다.

| 인덱스 | 요일 |
|---:|---|
| 0 | 월 |
| 1 | 화 |
| 2 | 수 |
| 3 | 목 |
| 4 | 금 |
| 5 | 토 |

파싱된 요일이 위 목록에 없으면 `-1`로 저장됩니다.

## Excel 데이터 형식

`parseExcelData()`는 한 행을 연관 배열 형태로 전달받는 것을 기준으로 작성되어 있습니다.

현재 코드에서 사용하는 Excel 열은 다음과 같습니다.

| 열 | 의미 | 반환 위치 |
|---|---|---|
| B | 과목코드 | `course->codes` |
| C | 과목명 | `course->name` |
| D | 학년 | `course->grade` |
| E | 분반 | `lecture->name`, `lecture->codes` |
| F | 이수구분 | `course->category` |
| H | 교수코드 | `professor->codes` |
| I | 교수명 | `professor->name` |
| K | 전공명 | `major->name` |
| L | 학점 | `course->point` |
| S | 강의시간 | `time` 배열 |

전공명(`K`)이 비어 있으면 `미지정`으로 처리합니다.

학년(`D`)과 학점(`L`)은 정수형으로 변환됩니다.

## 헤더 행 판별

`findStartRow()`는 다음 조건을 만족하는 행을 헤더로 인식합니다.

```text
A열 = No
B열 = 과목코드
```

조건이 맞으면 `1`, 아니면 `false`를 반환합니다.

## 분반 정보

분반은 과목명과 과목코드 뒤에 `-분반`을 붙이는 방식으로 생성합니다.

예를 들어 다음과 같은 데이터가 있다면:

```text
과목명: 자료구조
과목코드: CS101
분반: 01
```

다음과 같이 변환됩니다.

```text
lecture->name  = 자료구조-01
lecture->codes = CS101-01
```

## 강의시간 형식

강의시간은 Excel의 `S`열에서 읽습니다.

기본 형식은 다음과 같습니다.

```text
건물-호수:요일(교시,교시,...)
```

예:

```text
아리관-301:월(1,2)
```

여러 시간대가 있는 경우 닫는 괄호 뒤의 쉼표를 기준으로 각각 분리합니다.

```text
아리관-301:월(1,2),아리관-301:수(3,4)
```

파싱 결과 예시는 다음과 같습니다.

```php
$return->time[0]->day = 0;
$return->time[0]->start = 540;
$return->time[0]->end = 650;
$return->time[0]->classroom = '아리관 301호';
```

`start`와 `end`는 자정부터 경과한 **분(minute)** 단위 값입니다.

따라서 `540`은 오전 9시, `650`은 오전 10시 50분을 의미합니다.

## 교시 시간 계산

### 1~8교시

각 교시는 정각에 시작하고 50분 수업을 기준으로 계산합니다.

| 교시 | 시작 | 종료 |
|---:|---:|---:|
| 1 | 09:00 | 09:50 |
| 2 | 10:00 | 10:50 |
| 3 | 11:00 | 11:50 |
| 4 | 12:00 | 12:50 |
| 5 | 13:00 | 13:50 |
| 6 | 14:00 | 14:50 |
| 7 | 15:00 | 15:50 |
| 8 | 16:00 | 16:50 |

### 9~14교시

9교시는 17:00에 시작하며 이후 교시는 55분 간격으로 계산합니다. 각 수업의 종료 시각은 시작 시각 기준 50분 뒤입니다.

| 교시 | 시작 | 종료 |
|---:|---:|---:|
| 9 | 17:00 | 17:50 |
| 10 | 17:55 | 18:45 |
| 11 | 18:50 | 19:40 |
| 12 | 19:45 | 20:35 |
| 13 | 20:40 | 21:30 |
| 14 | 21:35 | 22:25 |

1보다 작은 교시 번호는 `false`, 14보다 큰 교시는 `9999`를 반환합니다.

## 반환 데이터 구조

`parseExcelData()`는 `stdClass` 객체를 반환합니다.

```text
return
├── major
│   └── name
├── course
│   ├── name
│   ├── codes
│   ├── category
│   ├── grade
│   ├── point
│   └── desc
├── lecture
│   ├── name
│   └── codes
├── professor
│   ├── name
│   └── codes
└── time[]
    ├── day
    ├── start
    ├── end
    ├── classroom
    └── classroom_building
```

강의시간이 비어 있거나 올바르게 파싱할 수 없는 시간 항목은 전체 행을 실패시키지 않고 해당 시간 정보만 건너뜁니다.

## PHP 8.4 호환성

현재 코드는 PHP 8.4 환경에서 발생할 수 있는 경고와 Deprecated 메시지를 줄이기 위해 다음 사항을 반영하고 있습니다.

- 누락된 Excel 배열 키를 `??` 기본값으로 처리
- 문자열 함수에 `null`이 전달되지 않도록 명시적 문자열 변환
- 잘못된 시간 데이터가 `min()` / `max()`에 전달되지 않도록 검증
- 여러 강의시간 항목을 `preg_split()`으로 안전하게 분리
- 상위 클래스 구조와의 호환성을 위해 `#[\AllowDynamicProperties]` 적용

PHP 8.4.23에서 문법 검사 및 주요 파싱 케이스를 확인했습니다.

## 주요 메서드

### `init()`

요일 배열을 초기화합니다.

### `findStartRow(array $data)`

Excel 헤더 행인지 판별합니다.

### `getPeriodStartTime($period)`

교시 번호를 시작 시각의 분 단위 값으로 변환합니다.

### `getPeriodEndTime($period)`

교시 번호를 종료 시각의 분 단위 값으로 변환합니다.

### `parseExcelData($data)`

Excel 한 행을 시간표 시스템에서 사용할 객체 구조로 변환합니다.

## 주의사항

이 저장소에는 상위 `timetable` 클래스나 Excel 파일 로더 자체는 포함되어 있지 않습니다. 따라서 실제 사용 시에는 해당 클래스를 제공하고 Excel 각 행을 `parseExcelData()`가 기대하는 배열 형태로 전달하는 상위 시스템이 필요합니다.
